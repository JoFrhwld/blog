    setup
    library(tidyverse)
library(tinytable)
library(tidynorm)
set.seed(2026-10-26)

    For a recap on why and how we do speaker vowel normalization, see the Introducing Tidynorm post. The new version of tidynorm introduces the ability to pre-aggregate formant values by vowel class to deal with imbalanced data.

    Motivation: Biased means

    To simulate an extreme example of imbalanced vowel class data, I’ll create a data set where one speaker only has 10% of their data, except for /iy/ which they have all of.

    speaker_data |>
  filter(
    plt_vclass != "iy",
    speaker == "s01"
  ) |>
  slice_sample(
    by = c(speaker, plt_vclass),
    prop = 0.1
  ) -> 
  s01

speaker_data |>
  filter(
    !(
      plt_vclass != "iy" &
      speaker == "s01"
     )
  ) -> 
 rest

bind_rows(
  s01, rest
) ->
imbalanced

    In Lobanov normalization, one of the normalization parameters we estimate is the mean frequency for each formant. Because of the difference in these two data sets, the means are fairly different, with the imbalanced data being pulled towards a lower F1 and a higher F2 for speaker s01.

    Calculating means
    imbalanced |>
  summarise(
    .by = speaker,
    across(F1:F3, \(x) mean(x, na.rm = T))
  ) |>
  tt(
    digits = 1,
    caption = "Imbalanced data means"
  )
speaker_data |>
  summarise(
    .by = speaker,
    across(F1:F3, \(x) mean(x, na.rm = T))
  ) |>
  tt(
    digits = 1,
    caption = "Full data means"
  )
    Imbalanced data means
    speaker F1 F2 F3
    s01 586 2150 3099
    s03 473 1485 2430
    Full data means
    speaker F1 F2 F3
    s01 637 1972 3028
    s03 473 1485 2430

    One way of dealing with this is to pre-aggregate the data by vowel class before calculating the overall means (called Lobanov 2.0 in Brand et al. (2021)). We can see below that it brings the imbalanced and full data parameters closer together.

    Calculating mean of means
    imbalanced |>
  summarise(
    .by = c(speaker, plt_vclass),
    across(F1:F3, \(x) mean(x, na.rm = T))
  ) |>
  summarise(
    .by = c(speaker),
    across(F1:F3, mean)
  ) |>
  tt(
    digits = 1,
    caption = "Imbalanced data mean of means"
  )
speaker_data |>
  summarise(
    .by = c(speaker, plt_vclass),
    across(F1:F3, \(x) mean(x, na.rm = T))
  ) |>
  summarise(
    .by = c(speaker),
    across(F1:F3, mean)
  ) |>
  tt(
    digits = 1,
    caption = "Full data mean of means"
  )
    Imbalanced data mean of means
    speaker F1 F2 F3
    s01 611 1892 3008
    s03 469 1401 2373
    Full data mean of means
    speaker F1 F2 F3
    s01 624 1890 2996
    s03 469 1401 2373

    While I’m framing this in terms of Lobanov normalization specifically, it’s potentially an issue for any vowel-extrinsic method, including

    • ΔF

    • Nearey

    • Watt & Fabricius

    Pre-aggregating in {tidynorm}

    In tidynorm 0.5.0, I’ve implemented a new .agg_by argument in all relevant point, track, and DCT normalization functions. You just need to pass it a vowel class column, and the relevant normalization function will pre-aggregate the formant data before calculating the normalization parameters.

    imbalanced |>
  norm_lobanov(
    F1:F3,
    .by = speaker
  ) ->
  imbalanced_lobanov
    Normalization info
• normalized with `tidynorm::norm_lobanov()`
• normalized `F1`, `F2`, and `F3`
• normalized values in `F1_z`, `F2_z`, and `F3_z`
• grouped by `speaker`
• within formant: TRUE
• (.formant - mean(.formant, na.rm = T))/(sd(.formant, na.rm = T))
    imbalanced |>
  norm_lobanov(
    F1:F3,
    .by = speaker,
    .agg_by = plt_vclass
  ) ->
  imbalanced_lobanov2
    Normalization info
• normalized with `tidynorm::norm_lobanov()`
• normalized `F1`, `F2`, and `F3`
• normalized values in `F1_z`, `F2_z`, and `F3_z`
• grouped by `speaker`
• within formant: TRUE
• Pre-aggregation column: plt_vclass
• (.formant - mean(.formant, na.rm = T))/(sd(.formant, na.rm = T))

    If we calculate the mean normalized F1 and F2 and plot them, we can see that the the speakers’ vowels are much more similar when we did pre-aggregation than without.

    calculating means
    imbalanced_lobanov |>
  summarise(
    .by = c(speaker, plt_vclass, ipa_vclass),
    across(
      ends_with("_z"),
      mean
    )
  ) |>
  mutate(
    method = "no pre-aggregation"
  ) ->
  imb_means

imbalanced_lobanov2 |>
  summarise(
    .by = c(speaker, plt_vclass, ipa_vclass),
    across(
      ends_with("_z"),
      mean
    )
  ) |>
  mutate(
    method = "pre-aggregation"
  ) ->
  imb_means2
    plotting code
    bind_rows(
  imb_means,
  imb_means2
) |>
 mutate(
   method = str_wrap(method)
 ) |>
 filter(
   plt_vclass %in% c("iy", "uw", "o", "@")
 ) |>
 ggplot(
   aes(F2_z, F1_z, color = speaker)
 ) + 
   geom_text(
     aes(label = ipa_vclass),
     family = "Noto Sans"
   ) + 
   scale_x_reverse() + 
   scale_y_reverse() +
   facet_wrap(~method)

last_plot() + theme_darkmode()
